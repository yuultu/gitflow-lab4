# Лабораторная работа № 4. GitFlow

**Цель** — освоить работу с ветками GitFlow, защиту веток и слияние изменений через pull request.

В учебном примере ветка `master` хранит выпущенную версию, а в `develop` собираются изменения. Поиск разрабатывается в `f_ex1`, экспорт — в `f_ex2`. После проверки обе ветки вливаются в `develop`. Релиз готовится в `release/1.0.0` и через pull request попадает в `master` и `develop`. Прямой push в `master` и `develop` должен быть запрещён.

## Распределение работы в бригаде

- **Счетчикова Мария (Maintainer)** — настройка репозитория, защита веток и выпуск релиза.
- **Ахмедов Азизбек (Developer)** — поиск в ветке `f_ex1`.
- **Музякова Александра (Developer)** — экспорт в ветке `f_ex2`.
- **Лебедев Александр (Reviewer)** — проверка изменений перед слиянием в `develop`.
- **Серов Глеб (Reviewer)** — проверка изменений перед выпуском релиза.
